# 腾讯风险监管决策平台

一个面向课堂展示的企业风险监管课程项目。项目以腾讯 `Tencent` 为案例对象，围绕监管合规、云与 AI 算力、国际化经营、商业信用与平台生态风险，构建从信息接入、智能评估、策略优化到 PDCA 执行闭环的可视化决策平台。

## 项目定位

这个项目不是传统看盘系统，而是一个更偏企业管理决策的风险监管驾驶舱。

它重点展示三件事：

- 把分散的监管、经营、国际业务和技术资源风险放到一个统一界面里
- 用图表和交互解释风险来源，而不是只给一个分数
- 让课堂展示形成完整链路：`信号接入 -> 风险评估 -> 策略生成 -> 执行闭环`

## 当前版本亮点

- 默认公司画像、场景数据、报告文本和首页叙事已统一切到腾讯
- 课堂展示主链路已统一为：`演示总控 -> 总览 Dashboard -> 场景中心 -> 智能评估 -> 策略优化 -> 报告中心`
- 风险主题升级为更贴近平台型科技企业的三条主线：
  - 监管合规风险
  - 云与 AI 算力风险
  - 国际化经营风险
- 明确区分官方披露数据与课堂建模参数，更适合答辩讲解

## 核心页面

- `演示总控`：适合课堂开场，快速说明对象、风险主题和展示路径
- `Dashboard 总览`：展示综合风险评分、趋势、构成和 AI 推荐动作
- `风险场景中心`：分为全球化经营、商业信用、AI 算力供应三类场景
- `智能风险评估中心`：展示 VaR、概率分布、因子贡献和爆发窗口
- `策略优化`：对比稳健、平衡、增长三套方案
- `PDCA 执行闭环`：展示方案执行、反馈与复盘
- `报告中心`：输出适合展示和汇报的结论报告

## 技术栈

- 前端：React 19 + TypeScript + Vite
- UI：Tailwind CSS
- 图表：ECharts + Lightweight Charts
- 数据组织：React Query + Zustand + Axios
- 后端：FastAPI + SQLAlchemy + APScheduler
- 存储：SQLite

## 启动方式

### 1. 安装前端依赖

```bash
npm install
```

### 2. 安装后端依赖

```bash
python -m pip install -r backend/requirements.txt
```

### 3. 启动后端

```bash
npm run backend:dev
```

默认地址：`http://127.0.0.1:8000`

### 4. 启动前端

```bash
npm run dev
```

默认地址：`http://127.0.0.1:5173`

## 课堂展示建议顺序

1. 从 `演示总控` 开场，说明这是腾讯风险监管决策平台
2. 进入 `Dashboard 总览`，展示整体风险和当前推荐动作
3. 打开 `风险场景中心`，重点讲国际业务、商业信用和 AI 算力
4. 进入 `智能风险评估中心`，解释评分不是拍脑袋，而是有模型和因子支持
5. 进入 `策略优化`，对比三套方案并突出系统推荐逻辑
6. 最后用 `报告中心` 收尾，形成完整汇报闭环

## 数据说明

- 腾讯控股年度业绩公告、年度报告、半年报等官方披露
- 微信及腾讯生态公开运营数据
- 港股公开市场信息
- 监管公开信息与行业公开研究资料

## 为什么先放分支，不直接进 main

因为分支更安全。

- 你仓库原来的 `main` 已经有自己的历史
- 我这边直接覆盖 `main` 有误伤现有内容的风险
- 先把腾讯版本完整放到 `codex/upload-tencent-platform`，你可以先预览、确认、再合并
- 等你看满意后，再把这个分支合到 `main`，这样记录也更清楚
